# Pre-entrega: Extracción y Almacenamiento Seguro de Datos vía API

Este proyecto es un script en Python que realiza peticiones GET a una API pública, extrae datos meteorológicos, aplica una transformación básica para filtrar campos relevantes y almacena la información estructurada en un archivo JSON.

## Requisitos previos

- Una clave API (API Key) gratuita de [OpenWeatherMap](https://openweathermap.org/)
